# 对标拆解：他们怎么做 GitHub 与网站

做这个项目之前，我们先把标杆逐个拆了一遍。结论有点反直觉：**他们的护城河不是内容质量，是「仓库 + 网站 + 私域」这套结构**。内容谁都能写，结构决定了能不能持续拉到人。

---

## 逐家拆解

| 对象 | GitHub 上做什么 | 自有网站做什么 | 转化怎么接 |
|---|---|---|---|
| **JavaGuide** | 156K+ star 的面试知识库；README 是多语言切换 + 徽章 + 按知识点平铺的大目录 + Star 趋势 + 公众号；内容本身即搜索资产 | `javaguide.cn` 文档站，「核心入口 / 精选文章 / 关于 / PDF 与微信」分区；另有 `interview.javaguide.cn` 突击版 | 后台回复关键词领 PDF；微信扫码加好友；星球 |
| **小林 coding** | 内容同步沉淀；真正的入口是公众号与网站 | `xiaolincoding.com`：必看系列（图解网络/系统/MySQL/Redis，现已扩到图解 Agent、Claude Code、Codex）、面试项目、训练营、求职工具、求职之路、作者自述 | 公众号首发 + 扫码加群；免费工具（简历、校招表格）当入口；训练营变现 |
| **程序员鱼皮 / 编程导航** | 开源免费资料库（ai-guide 等）当 SEO 资产 | 编程导航站点 + 面试鸭 + 老鱼简历，产品矩阵本身就是入口 | 公众号沉淀 → 付费社群；产品相互导流 |
| **二哥（Java3y）** | GitHub 收录沉淀，`javabetter.cn` 同步；「面渣逆袭」搜索占位 | 自建站 + 公众号，免费 PDF 攒口碑 | 「回复关键词领面渣逆袭」→ 星球 |
| **代码随想录** | 刷题笔记开源；把原本星球付费的《最强八股文》第六版全面免费开源 | 卡码笔记网站承载在线版（体验更好、更新更及时） | 免费资料换长尾流量，**训练营 / 服务变现** |
| **芋道源码** | `ruoyi-vue-pro` MIT 全开放，作为最大流量入口 | 演示站需关注公众号取验证码；核心文档「星球 VIP 可见」 | 三层漏斗：开源 → 演示站 → 星球 |

## 共同模式：四层结构

```
① 永久入口   GitHub 仓库 + 自建站
             内容被搜索引擎长年收录，一次投入、永久引流
② 私域中枢   公众号
             唯一能反复触达的自有阵地；关键词回复是标准动作
③ 放大器     知乎 / 掘金 / CSDN / 牛客 / B站 / 抖音 / 小红书 / 大号转载
             一稿多铺，不逐平台创作
④ 承接变现   知识星球 / 微信 / 免费工具
             卖服务（答疑、简历、内推、陪跑），不是卖课程
```

再叠一条冷启动杠杆：**给大号投稿、求转载、混圈子**。小林 10 篇文章破万粉，主力是单篇被转载 52 次；鱼皮靠连续 100 天直播与混圈子破局，而不是闭门日更。

## README 的标准骨架（我们实测抓过）

把三家标杆仓库的 README 拉下来比对，结构高度一致：

```
多语言切换 / 在线阅读优先（网站是主入口，GitHub 是背书）
  → Logo + 徽章组（stars / forks / license / contributors / PRs / Trendshift）
  → 项目介绍（为什么做、解决什么痛点）
  → 快速开始（在线阅读 / 本地阅读 / 你将收获什么）
  → 内容导航（按知识体系分大类）
  → 如何学习 / 使用建议
  → PDF 版本下载、读者交流群、公众号
  → 如何贡献、致谢、核心贡献者
  → Star History、引用、开源协议
```

**关键细节**：在线阅读链接被放在最顶部，甚至排在介绍之前——他们清楚地知道 GitHub 只是「信任状」，真正的用户停留时间在自有站。

## 网站的共同信息架构

| 区块 | 作用 |
|---|---|
| 顶部导航（分类 + 搜索 + GitHub 入口） | 降低跳出，强化开源背书 |
| Hero / 一句话定位 | 3 秒说清「这是给谁的」 |
| 核心入口卡片（分系列） | 把大部头拆成可点的路径 |
| 左侧目录树 + 右侧正文 + 页内 TOC | 长文可读、可跳转 |
| 精选文章 / 关于作者 | 建立人格与信任 |
| 资料下载 / 二维码 / 交流群 | 转到私域 |
| 页脚：备案、协议、Star | 合规与背书 |

他们大多用 VitePress / VuePress 一类默认主题——**稳定、好维护，但长得都一样**。这正是可以超越的地方。

## 我们的超越点

| 维度 | 他们 | AgentOffer |
|---|---|---|
| 内容组织 | 按知识点平铺（Java / 网络 / 数据库…） | **按岗位能力模型 + 五阶段路线**，每篇带验收点与追问链 |
| 内容深度 | 讲「是什么」为主 | 讲「出问题怎么办」：可运行代码、故障注入、评测口径、数字口径 |
| 资料出处 | 多为原创或转载 | **一手资料地图**页保留全部原始链接，可核验，不搬运 |
| 岗位情报 | 几乎没有 | JD 拆解、三类岗位画像、笔试平台情报持续更新 |
| 视觉 | 默认文档主题，同质化 | 自定义设计：亮/暗主题、阅读进度、全文搜索、路线图、卡片、响应式 |
| 工程形态 | 依赖构建工具链 | **零依赖 Node 服务**，`docs/` 一份源同时驱动仓库与网站 |
| 转化链路 | 关键词回复 → 微信 | 目录页即资料包钩子，路径更短；平台上只做情报与辅导 |
| 域名与自有资产 | 各自独立域名 | `agent.meetoffer.cn`，复用已有备案与通配证书 |

**一条最重要的判断**：他们卖的是「教你自己学」，我们服务的是「下周就要笔试 / 面试」的人。所以内容不能只堆知识，必须能直接转化成「面试时讲得出来的证据」——这也是为什么每篇都以验收点和追问链收尾。
